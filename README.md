# MK1 ONLINE CHECK

Крошечная консольная проверка для Windows: **доступен ли онлайн-бэкенд
Mortal Kombat 1 с вашего текущего подключения** и в чём именно проблема.

Ничего не устанавливает, не меняет настройки, не требует прав
администратора. Один запуск — один ответ.

---

## Зачем это нужно

Онлайн в MK1 работает не через Steam, а через собственный бэкенд
Warner Bros. — **Hydra**, адрес которого лежит в файле игры:

```
MK12\Server\endpoint.json  ->  https://k1-api.wbagora.com
```

WB закрывает доступ к нему по **стране IP** и отвечает
`HTTP 451 Unavailable For Legal Reasons` с кодом `hydra_error: 1055`.
Поэтому типичная история выглядит так:

> «Поменял DNS на Cloudflare/Google/OpenDNS — онлайн так и не появился».

Это нормально: DNS тут ни при чём. Все резолверы отдают **один и тот же**
адрес сервера, а блокировка срабатывает уже по IP, с которого вы пришли.
Смена DNS не может изменить вашу страну.

Проверка показывает за 3 секунды, где именно вы застряли: в сети, в
гео-блоке или уже в аккаунте.

---

## Запуск

Двойной клик по **`mk1check.cmd`**.

Включите VPN (если пользуетесь) — и сравните два запуска: с ним и без.

```
 MK1 ONLINE CHECK   11:50:03
==================================================================
 1) Выход в интернет: 188.162.12.212  [RU]  PJSC MegaFon
 2) k1-api.wbagora.com -> 44.197.89.18, 3.227.77.16
 3) https://k1-api.wbagora.com/v1/health -> HTTP 451
    ответ бэкенда: hydra_error=1055

 ВЕРДИКТ: БЛОК ПО СТРАНЕ (HTTP 451, Unavailable For Legal Reasons). hydra_error=1055
==================================================================
```

---

## Как читать результат

| Строка 3 | Что значит |
|---|---|
| **451** (+ `hydra_error=1055`) | Сервер доступен, но WB блокирует вашу страну. Проблема не в DNS и не в вашем интернете |
| **403** | До сервера дошли и гео-гейт пройден. Это нормальный ответ на запрос без авторизации |
| **401 / 404 / 200** | Сервер отвечает нормально, гео-блокировки нет |
| **ERR / таймаут** | Не установилось соединение: нет интернета, режет файрвол или не работает VPN |

Смотрите также строку 1: если там `[RU]`, а вы «под VPN» — значит туннель
не несёт трафик (раздельное туннелирование) либо сервер VPN стоит в РФ.

---

## Что делать по результату

* **451 при российском IP** — нужен VPN с выходом в поддерживаемой стране
  (NL, DE, FI, PL, US…) и режим «весь трафик через VPN», а не раздельное
  туннелирование. Затем перезапустить проверку: код должен смениться на
  403/404.
* **451 даже при не-российском IP** — WB смотрит не только на IP. Дальше
  вопрос региона аккаунта WB, локально это не лечится.
* **ERR** — сначала поднимите обычный интернет: `netcheck.cmd` покажет,
  живы ли DNS и TCP.

## Что внутри

| Файл | Назначение |
|---|---|
| `mk1check.cmd` | запуск в один клик |
| `mk1check.ps1` | сама проверка, PowerShell 5.1 (встроен в Windows 10/11) |
| `netcheck.cmd` / `netcheck.ps1` | общая диагностика сети: DNS по UDP/53, TCP/443, DoH, метрики адаптеров |

Код возврата `mk1check`: **0** — сервер ответил (гео-блока нет), **1** —
451 или нет связи. Удобно для скриптов и батников.

Утилита обращается ровно к двум адресам: `ifconfig.co` (узнать ваш
внешний IP и страну) и `k1-api.wbagora.com` (сам API игры). Никакой
телеметрии, установки и фоновых процессов.

---

## Честные границы

Это **диагностика, а не обход блокировки**. Она не проксирует трафик, не
меняет DNS и не обещает, что онлайн заработает. Её задача — за минуту
показать, DNS у вас виноват или нет, и не тратить вечер на перебор
резолверов.

Если раньше «помогала смена DNS» — почти наверняка это был **Smart DNS**
(сервис, который не только подменяет адрес, но и проксирует нужные хосты
через себя). Обычный DNS на ответ `451` повлиять не может: он зависит от
IP клиента, а не от того, кто выдал IP сервера.
